# 赵杉 - AI 产品经理作品集

## 投标文件智能生成工作台

AI 驱动的招投标文件自动化生成平台，将 LLM 大模型能力与能源行业招投标场景深度结合。

### 核心功能

- 上传招标文件（.docx / .pdf / .txt），自动解析
- LLM 精准提取 100+ 条技术要求，标注来源章节
- 四步法深度扩充方案：设计 → 实现 → 安全 → 验收
- 一键生成符合央企格式规范的 Word 文档

### 技术栈

React 19 · TypeScript · Vite · FastAPI · Python · SSE 流式 · LLM 提示词工程 · python-docx · Ant Design 6
